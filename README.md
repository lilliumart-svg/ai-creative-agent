# Samsung Creative Brief — Automation Engine

Автоматизация брифинга и генерации digital-креативов: из Excel-файла с моделями и акциями
на выходе — готовые креативы под все paid-форматы, каждый в PSD (редактируемый) и JPG (финал).

## Что делает

1. Читает `samsung-creative-brief-template.xlsx`, находит главную (розовым выделенную) модель
   на вкладке «1. Вводные».
2. Валидирует данные (обязательные поля, корректность скидки).
3. Генерирует структурированный бриф по модели (`brief.json`).
4. Рендерит креатив под 4 формата: Feed Square, Feed Portrait, Stories/Reels, Display —
   строго по гайдлайну из вкладки «2. Форматы» (разрешение, safe zone, позиция логотипа,
   clear space).
5. Автоматически проверяет соблюдение safe zone/clear space перед экспортом.
6. Экспортирует каждый формат как:
   - многослойный **PSD** (слои: фон, товар, логотип, заголовок, фичи, цена, бейдж объёма —
     каждый редактируется отдельно в Photoshop),
   - плоский **JPG**.

## Веб-инструмент (index.html)

Открой `index.html` (двойной клик — работает в любом браузере, без сервера) — это интерактивный
конструктор креативов:

- **Выбор формата** — 4 кнопки, живое превью на canvas в реальном разрешении
- **Загрузка Excel** — подтягивает бриф из вкладки «Вводные» автоматически
- **Логотип уже встроен** в файл — грузить каждый раз не нужно
- **Фото товара можно заменить** — для другой модели загружаешь новый PNG
- **Оверлей safe zone** — визуально проверить, что ничего не выходит за границы
- **Скачать JPG** — текущий формат, или **всё архивом (ZIP)** — все 4 формата разом
- **Скачать PSD** — ссылки на файлы, собранные через `engine.py` (см. ограничение ниже)

**Важно:** PSD в браузере не собрать (нужен Photoshop/ImageMagick на сервере), поэтому кнопки
PSD ведут на файлы из последнего запуска `engine.py`. Если поменяешь поля в форме сайта —
обновится только JPG-превью; чтобы то же самое ушло в PSD, перезапусти `engine.py` с новыми
данными в Excel.

## Как запустить

```bash
pip install openpyxl pillow
# ImageMagick должен быть установлен (нужен для сборки PSD): sudo apt install imagemagick
python3 engine.py
```

Готовые файлы появятся в папке `output/`.

## Чтобы прогнать на файле следующего месяца

Замени `samsung-creative-brief-template.xlsx` на новый файл с тем же названием (или поменяй
`INPUT_PATH` в начале `engine.py`). Движок сам найдёт розовым выделенную модель и посчитает
всё заново — структура кода не завязана на конкретные значения текущего месяца.

Если нужно сгенерировать другую модель вместо розовой — поменяй логику выбора строки
в `load_main_model()` (сейчас: розовая заливка → первая строка данных как запасной вариант).

## Использованные инструменты

- **Claude** — сборка пайплайна, промпт-инжиниринг раскладки элементов под 4 формата
- **Python** (openpyxl, Pillow) — вся логика: чтение Excel, валидация, рендер креативов
- **ImageMagick** — сборка отдельных PNG-слоёв в один многослойный PSD

## Про промпты

Конкретные формулировки промптов и логику раскладки элементов (защита от наложений,
адаптация под safe zone разных форматов) сознательно не привожу дословно в этом README —
это часть авторского подхода к промпт-инжинирингу, которую готова показать и разобрать
устно на защите, но не оставляю в виде копируемого рецепта в публичном репозитории.

## Ограничения текущей версии (MVP)

- Шрифт — Outfit (близкий по духу гротеск), не оригинальный SamsungOne/Sharp Sans —
  оригинал не был предоставлен для тестового задания.
- Логотип и референс-фото стиральной машины — из открытых источников, не официальные
  ассеты бренд-гайда.
- Обработана 1 модель (WW80AK6L28BBLT), как и требовалось для теста — движок технически
  готов обработать все строки файла за один проход (см. бонусные баллы в задании).

## Deliverables в этой папке

- `Feed Square.psd` / `.jpg` — 1080×1080
- `Feed Portrait.psd` / `.jpg` — 1080×1350
- `Stories-Reels.psd` / `.jpg` — 1080×1920
- `Display.psd` / `.jpg` — 1200×628
- `brief.json` — автоматически сгенерированный бриф по модели
- `engine.py` — весь пайплайн
- `assets/`, `fonts/` — используемые ассеты
