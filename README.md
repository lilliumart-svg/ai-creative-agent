# Samsung Creative Brief — Automation Engine

Автоматизация брифинга и генерации digital-креативов: из Excel-файла с моделями и акциями
на выходе — готовые креативы под все paid-форматы, каждый в PSD (редактируемый) и JPG (финал),
плюс видео-формат.

Два способа получить одно и то же: `index.html` (интерактивный сайт, ничего устанавливать не
нужно) и `engine.py` (Python-пайплайн для пакетной обработки/автоматизации).

## Что делает

1. Читает `samsung-creative-brief-template.xlsx`, находит главную (розовым выделенную) модель
   на вкладке «1. Вводные» — либо, при пакетном режиме, читает **все** строки разом.
2. Валидирует данные (обязательные поля, корректность скидки).
3. Генерирует структурированный бриф по модели.
4. Рендерит креатив под 4 обязательных формата — Feed Square, Feed Portrait, Stories/Reels,
   Display — строго по гайдлайну (разрешение, safe zone, позиция логотипа, clear space) —
   плюс отдельный **5-й формат Video (1920×1080, safe zone 90px)** с собственной спекой,
   не анимация одного из четырёх статичных.
5. Автоматически проверяет соблюдение safe zone/clear space перед экспортом.
6. Экспортирует каждый формат как:
   - многослойный **PSD** (слои: фон, товар, логотип, заголовок, фичи, цена, бейдж объёма,
     логотип партнёра — каждый редактируется отдельно в Photoshop),
   - плоский **JPG**.
7. Видео-формат — короткий зацикленный MP4/WebM (3.5 сек): элементы поочерёдно проявляются
   (товар → лого → заголовок → фичи → цена), лёгкий zoom на товаре.

## Веб-инструмент (index.html) — открой и работай сразу, без установки

- **5 форматов** в один клик, включая Video — живое превью на canvas в реальном разрешении
- **Библиотека из 6 моделей** (WW80AK6L28BBLT, WW65AK4S21CELT, RB37A5411EL/WT, RB53DG703EB1WT,
  NV75T9979CDWT, AR80F09CABWNER) — уже встроены, выбираются кликом; своё фото тоже можно
  загрузить (автообрезка от прозрачных полей)
- **Партнёр/канал** — ALL / Mechta / Sulpak / Technodom: лого партнёра + цена в его бренд-цвете
- **RU / KZ** — переключатель языка текста на креативе
- **Загрузка Excel** — подтягивает бриф автоматически; если строк больше одной — предлагает
  массовую генерацию (JPG-архив или PSD-архив на все товары × все форматы)
- **PSD собирается прямо в браузере** (библиотека `ag-psd`, чистый JS) — из тех самых слоёв,
  что видно в превью, с любыми правками полей и выбранным партнёром. Не требует Photoshop
  или сервера.
- **Видео** — запись анимации через `MediaRecorder` (нативный API браузера), скачивается как
  `.webm`
- **Оверлей safe zone** — визуально проверить, что ничего не выходит за границы

## Python-пайплайн (engine.py + video_engine.py) — для автоматизации/CI

```bash
pip install openpyxl pillow
sudo apt install imagemagick   # нужен для сборки PSD
python3 engine.py              # 1 модель (розовая строка) → 4 формата, PSD+JPG
python3 video_engine.py        # тот же товар → Video.mp4 (1920×1080)
```

Пакетный режим — все модели файла разом:

```python
from engine import export_all
export_all()   # -> output/all/<Модель>/<Формат>.psd/.jpg, для каждой строки файла
```

## Чтобы прогнать на файле следующего месяца

Замени `samsung-creative-brief-template.xlsx` на новый файл с тем же названием. Движок сам
найдёт розовым выделенную модель (или обработает все строки через `export_all()`) и
посчитает всё заново — структура кода не завязана на конкретные значения текущего месяца.
Если новых моделей нет в библиотеке фото — подставится дефолтное изображение автоматически,
без падения скрипта.

## Использованные инструменты

- **Claude** — сборка пайплайна и веб-инструмента, промпт-инжиниринг раскладки элементов
- **Python** (openpyxl, Pillow) — чтение Excel, валидация, рендер креативов, видео-кадры
- **ImageMagick** / **ffmpeg** — сборка PSD (Python-версия) и кодирование видео
- **ag-psd** (JS) — сборка PSD прямо в браузере
- **SheetJS, JSZip** (JS) — чтение Excel и упаковка архивов на сайте

## Про промпты (кратко)

Промпты строились вокруг трёх задач: (1) распарсить Excel и найти нужную модель/строку,
(2) разложить элементы креатива (лого, заголовок, товар, цена, бейдж) под safe zone каждого
формата без наложений, (3) собрать то же самое как интерактивный инструмент с живым превью.
Точные формулировки не привожу дословно — общий подход готова разобрать устно на защите.

## Ограничения текущей версии (MVP)

- Шрифт — Outfit/DejaVu Sans (близкие по духу гротески с полной поддержкой кириллицы и
  казахских букв), не оригинальный SamsungOne/Sharp Sans — оригинал не был предоставлен.
- Логотипы и референс-фото — из открытых источников/присланных ассетов, не официальные файлы
  бренд-гайда.
- Обязательный тест — 1 модель (WW80AK6L28BBLT), 4 формата, PSD+JPG — выполнено полностью;
  всё сверх этого (библиотека моделей, каналы, RU/KZ, видео, массовая генерация) — бонусы.
